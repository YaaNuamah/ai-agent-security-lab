# Project Scope

## Assignment

Design an implementation plan for **Z2: Agent Lab**, covering AI agent development and security. The work should help organizers understand what to build, what participants will do, what resources are required, and how the zone can operate safely.

## In Scope

- Comparable event and workshop research
- Four proposed hands-on activities
- Beginner-to-advanced participant journey
- Technical and network architecture
- Model, API, software, and hardware requirements
- Agent attack and defense scenarios
- Safety, isolation, monitoring, and reset controls
- Facilitator skills, staffing, timing, and participant capacity
- Cost assumptions and low-connectivity/offline fallbacks
- Ghana-specific feasibility and accessibility
- Prototype plan and evaluation criteria

## Out of Scope

- Testing third-party systems without written authorization
- Collection or publication of real credentials or personal data
- A production autonomous security agent
- Final event procurement before organizer approval
- Claims not supported by a source, test result, or clearly labeled assumption

## Key Questions

1. What should each participant learn and produce?
2. Which threats can be demonstrated safely and meaningfully?
3. Which architecture minimizes cost and operational risk?
4. What must work offline or with unreliable connectivity?
5. How quickly can a station be reset between participants?
6. What facilitator-to-participant ratio is realistic?
7. How will the organizers measure learning and success?

## Definition of Done

The research is ready for review when the implementation report includes evidence-backed recommendations, four activity specifications, an architecture, safety controls, staffing and cost estimates, fallback modes, measurable success criteria, and a list of decisions still required from organizers.
